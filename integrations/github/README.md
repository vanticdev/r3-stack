# GitHub integration

Reserved for repository revision references, change events, workflow triggers,
and publishing validation results. The orchestrator decides which jobs to run;
this adapter handles GitHub-specific communication.

Documentation only. Git stores authored robot inputs and artifact references;
it is not the store for live simulation state or large generated artifacts.
No workflows, credentials, webhooks, or external connections are created here.

See [repository layout](../../docs/architecture/repository-layout.md).
