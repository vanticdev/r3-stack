# Electronics integration: KiCad candidate

Reserved for importing schematics, netlists, board geometry, footprints,
connector mappings, and manufacturing artifact references into the robot model.
KiCad is a provisional provider choice, not a committed dependency.

Documentation only. Circuit behavior and component ratings require explicit
models and metadata beyond PCB geometry or a netlist. Shared electrical and
wiring behavior belongs in domain packages rather than this import adapter.

See [repository layout](../../docs/architecture/repository-layout.md).
