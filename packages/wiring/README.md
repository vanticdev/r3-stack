# Wiring

Reserved for electrical connections and physical cable routing, linked through
shared connection identities. Electrical checks cover ratings, resistance,
voltage drop, and dissipation; physical checks cover length, slack, bend radius,
clearance, and moving-part interference.

Documentation only. Begin with static paths and conservative clearance checks;
the future visual editor belongs in `apps/web/`. Do not equate electrical
validity with a mechanically safe route.

See [repository layout](../../docs/architecture/repository-layout.md).
