# Simulation

Reserved for shared simulation clocks, event ordering, state exchange, engine
adapters, and coupling between mechanical, electrical, and sensor models.
Define validation results with input revisions, model assumptions, and diagnostic
artifact references. Job execution belongs in `services/simulation-worker/`.

Documentation only. No physics engine, coupling algorithm, or fidelity target
has been selected. Simulation success must not imply guaranteed hardware success.

See [repository layout](../../docs/architecture/repository-layout.md).
