# Unified robot model

Reserved for the versioned declarative robot specification and its derived
component/dependency graph. Own stable component and connector identities,
coordinate frames, units, revision references, and cross-domain relationships.

Documentation only. YAML is the proposed authoring format; no schema or parser
is defined yet. Keep this foundation independent of provider SDKs, application
entrypoints, and simulation engines.

See [repository layout](../../docs/architecture/repository-layout.md).
