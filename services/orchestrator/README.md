# Orchestrator

Reserved for the project API and coordination of versioned robot inputs,
dependency checks, validation jobs, simulation jobs, and deployment requests.
Store references to artifacts and results rather than live simulator state in
Git. Compose shared packages and external integrations here.

Documentation only. API contracts, persistence, job transport, and hosting are
undecided. This folder does not replace the existing `backend/` deployment API.

See [repository layout](../../docs/architecture/repository-layout.md).
